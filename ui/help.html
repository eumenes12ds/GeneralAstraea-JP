プリセットの正規表現（Regex Preset Binder）

正規表現スクリプトをSillyTavernのプリセットに組み込み、標準機能と同じ感覚で管理・切り替えできます。

プリセット内蔵の正規表現

標準版にはプリセットと正規表現を一緒に読み込む機能がありません。このスクリプトでは関連する正規表現を内蔵し、プリセットの読み込み時に自動で利用できます。

充実した操作画面

標準の正規表現画面と同様に、有効化・無効化、編集、読み込み・書き出し、並べ替え、複数選択を行えます。

ワンクリックで切り替え

ボタン一つで「共通 ↔ プリセット」間を移動し、スクリプトの紐づけと解除を行えます。

使い始める

  1. このスクリプトをインストールします（完了済み）
  2. 設定 → Regexを開くと、「プリセットに紐づく正規表現」の領域が追加されています。
  3. プリセットの正規表現を読み込むまたはプリセットの正規表現を新規作成から、使用するルールを設定します。
  4. 「⬆ プリセットに紐づけ／⬇ 共通へ戻す」で両方の領域を切り替えます。
  5. ドラッグで並べ替え、保存します。
// 共通スクリプトに「プリセットに紐づけ」ボタンが表示されます:
// 押すとextensions.regexから除かれ、プリセット一覧に追加されます（promptsに保存）。
// 逆方向の「共通へ戻す」も同様です。
ヒント: プリセットのデータは、chatCompletionSettings.promptsの識別子regexes-bindingsにJSON文字列として保存されます。

よくある質問

プリセットの正規表現をドラッグできなくなった場合は？

このスクリプトを一度無効にして、再度有効にしてください。

紐づけた項目を一括削除できますか？

SillyTavernの画面側の制約により、一括削除はできません。個別に削除するか、共通へ戻してから一括処理してください。
